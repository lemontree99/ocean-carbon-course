# 数据目录与格式说明

## 1. 当前目录原则

项目只保留最终报告能够直接复现的输入。三模式均使用`r1i1p1f1`：GFDL-ESM4采用`gr`网格，MPI-ESM1-2-LR和CanESM5采用`gn`网格。模式文件位于`data/raw/<model>/<experiment>/`。

## 2. 模式输入

| 文件 | 实验 | 用途 |
|---|---|---|
| `areacello.nc` | historical | 所有面积积分和面积加权 |
| `fgco2.nc` | historical、ssp585、piControl | 全球碳汇、空间分布、漂移检验和自洽性通量积分 |
| `dissic_slices.nc` | historical、ssp585 | 首末月DIC库存端点 |
| `volcello.nc` | historical、ssp585 | DIC三维库存积分 |
| `mechanism_carbonate_surface_30yr_mean.nc` | historical、ssp585 | 1985–2014和2071–2100年表层DIC、TA日数加权平均 |
| `mechanism_stratification_30yr_mean.nc` | historical、ssp585 | 同期约0、200、1000 m温度和盐度日数加权平均 |

`fgco2`单位为kg C m⁻² s⁻¹，进入海洋为正；`areacello`为m²；`dissic`和`talk`为mol m⁻³；`volcello`为m³；`thetao`为°C；`so`数值约34。

机理平均场由`scripts/00_data_preprocessing/02_download_mechanism_window_means.py`从Pangeo CMIP6目录流式计算，只保存最终30年均态。源地址记录在`data/preprocessing/mechanism_30yr_manifest.json`。

## 3. 外部资料

| 路径 | 用途 |
|---|---|
| `data/obs/gcb/gcb2025_ocean_sink.csv` | 1959–2014年全球碳汇验证 |
| `data/obs/landschutzer/spco2_1982-2015_MPI_SOM-FFN_v2016.nc` | 1982–2014年空间分布验证 |
| `data/obs/co2/co2_concentration_1850_2100.csv` | 官方historical与SSP5-8.5大气CO₂浓度 |
| `data/obs/shapefiles/ne_110m_coastline.geojson` | 空间图海岸线 |

input4MIPs原始NetCDF和来源元数据保留在`data/obs/co2/input4mips/`及其上级目录，拼接脚本为`01_prepare_input4mips_co2.py`。

## 4. 完整性检查

在项目根目录运行：

```powershell
python scripts/00_data_preprocessing/00_validate_inputs.py
```

该脚本检查三个模式共36个必需模式文件的存在性与关键变量，并检查5个公共输入。日常重算不需要重新下载数据。

## 5. 已清理内容

2014/2100单年机理端点、完整`tos/sos/mlotst`、静态`thkcello`、稀疏piControl DIC、SOCAT参考数据、早期`legacy`结果和独立机制复核目录均不进入最新版报告，已从项目中移除。正式机制分析统一采用两个30年平均窗口。
