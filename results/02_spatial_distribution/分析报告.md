# 第二项分析：海洋碳汇空间分布

## 1. 分析目标与数据

目标是检验三个CMIP6模式能否再现现代海气CO₂通量的主要空间结构，并判断各模式在哪些海区
吸收过强、吸收过弱或位置出现偏差。

共同分析时期为1982–2014年：

- 模式：GFDL-ESM4、MPI-ESM1-2-LR和CanESM5的historical `fgco2`；
- 观测参照：Landschützer SOM-FFN v2016的`fgco2_raw`；
- 模式面积：各模式原生网格的`areacello`；
- 海岸线：Natural Earth 110 m。

使用`fgco2_raw`而不是经过时间平滑的场。所有最终地图和偏差统计均未进行时间平滑。

## 2. 计算步骤

### 2.1 模式单位和时间积分

CMIP6 `fgco2`单位为kg C m⁻² s⁻¹，向下进入海洋为正。对1982–2014年的每个月，使用文件中的
CF时间边界计算月份秒数，然后在每个原生格点计算33年平均的年度通量：

\[
F_{model}=\frac{1}{33}\sum_t fgco2_t\,\Delta t_t\frac{1000}{12.0107},
\]

其中1000把kg转换为g，12.0107 g mol⁻¹为碳的摩尔质量，最终单位为mol C m⁻² yr⁻¹。

GFDL-ESM4和CanESM5采用noleap日历，MPI-ESM1-2-LR采用proleptic Gregorian日历，计算中保留
各模式的真实月份长度。

### 2.2 Landschützer处理

Landschützer `fgco2_raw`已经是mol C m⁻² yr⁻¹，但符号为向上离开海洋为正。因此：

1. 把绝对值大于100的`1e20`缺测哨兵转换为NaN；
2. 按每月实际秒数计算1982–2014加权平均；
3. 乘以−1，使正值统一表示海洋吸收。

**Landschützer是观测约束产品，不存在piControl，也不需要漂移订正。**

### 2.3 为什么不能减去piControl完整空间气候态

主空间比较同样没有从模式historical场中逐格减去piControl气候态。原因是Landschützer表示海气
总净通量，其中包括赤道太平洋自然放气、高纬自然吸收等背景结构；模式piControl空间场也包含这些
自然背景。若逐格相减，会删除需要与观测比较的主要空间型。

piControl的完整空间气候态包含自然背景通量，不能把它当作漂移。正确方法是只估计每个格点随时间
变化的趋势，并减去该趋势相对historical分支时刻的累计量；截距和逐年控制波动都不扣除。

### 2.4 逐格空间漂移检验

对每个模式在原生网格上选取与1850–2100平行的251年piControl段，将年平均`fgco2`换算为
mol C m⁻² yr⁻¹，并逐格拟合

\[
F_{pi}(x,t)=a(x)+b(x)t+\varepsilon(x,t).
\]

使用Newey–West异方差和自相关一致标准误，最大滞后设为30年；随后在所有有效海洋格点上进行
Benjamini–Hochberg FDR订正，控制\(q=0.05\)。1982–2014平均年份为1998年，因此该气候态中由
控制趋势造成的累计漂移为

\[
D(x)=b(x)(1998-1850)=148b(x).
\]

将“需要订正区域”预先定义为同时满足：FDR显著，并且\(|D(x)|\ge0.10\) mol C m⁻² yr⁻¹。
第二项条件避免把统计显著但相对于约0.73–0.90 mol C m⁻² yr⁻¹模式—观测RMSE极小的变化误判为
具有实际影响的漂移。

| 模式 | 漂移空间RMS | 漂移RMS/空间偏差RMSE | 原始p<0.05面积 | FDR显著面积 | 需要订正面积 |
|---|---:|---:|---:|---:|---:|
| GFDL-ESM4 | 0.0898 | 12.0% | 17.95% | 4.13% | 1.44% |
| MPI-ESM1-2-LR | 0.0358 | 4.9% | 9.44% | 0.38% | 0.15% |
| CanESM5 | 0.0467 | 5.2% | 8.11% | 0.61% | 0.27% |

三个模式的面积平均漂移分别只有−0.0049、−0.0010和−0.0028 mol C m⁻² yr⁻¹，与全球积分
稳定性检验一致；但局地正负趋势会相互抵消。需要订正的面积都很小，因此不对整幅historical空间场
统一扣除一个常数，也不减去piControl气候态。只在上述标记格点实施

\[
F_{corrected}(x)=F_{historical}(x)-D(x),
\]

其他格点保持原值。该订正先在各模式原生网格上完成，再用相同的面积守恒方法汇总到2°共同网格。

### 2.5 共同网格

四套数据先在原生网格形成气候态，再用源格点面积加权汇总到2°共同网格：

\[
F_j=\frac{\sum_{i\in j}F_iA_i}{\sum_{i\in j}A_i}.
\]

该方法保持离散面积积分守恒，不使用双线性插值或绘图平滑。源格点按中心归入2°目标格，因此它是
一阶守恒汇总，不是严格的球面多边形重叠算法；2°分辨率在可读性、覆盖完整性和边界误差之间取得
折中。

### 2.6 统计量

在模式和Landschützer共同有效的2°海洋格点上，以Landschützer海洋面积为权重计算：

- 面积加权平均偏差：模式减观测；
- RMSE；
- 去除各自空间均值后的面积加权型相关；
- 共同掩膜上的积分通量；
- 五个重点海区的平均偏差、RMSE、型相关及积分偏差。

偏差为正表示模式吸收过强或放气过弱；偏差为负表示吸收过弱或放气过强。

## 3. 漂移订正后的全球空间统计

| 模式 | 型相关 | RMSE | 平均偏差 | 模式积分 | Landschützer积分 |
|---|---:|---:|---:|---:|---:|
| GFDL-ESM4 | 0.818 | 0.757 | +0.139 | 1.906 | 1.368 |
| MPI-ESM1-2-LR | 0.741 | 0.735 | +0.088 | 1.707 | 1.368 |
| CanESM5 | 0.704 | 0.899 | +0.082 | 1.684 | 1.368 |

RMSE和平均偏差单位为mol C m⁻² yr⁻¹，积分单位为Pg C/yr。

GFDL-ESM4的空间型相关最高，说明洋盆尺度的位置和正负分布最接近Landschützer。MPI的RMSE略低，
但空间型相关弱于GFDL。CanESM5的型相关最低且RMSE最大，整体空间表现最差。三个模式在共同掩膜
上的净吸收均强于未经GCB归一化的Landschützer原始产品。

### 3.1 订正前后对照

| 模式 | 平均偏差（原始→订正） | RMSE（原始→订正） | 型相关（原始→订正） | 积分（原始→订正） |
|---|---:|---:|---:|---:|
| GFDL-ESM4 | +0.1412 → +0.1392 | 0.7503 → 0.7566 | 0.8202 → 0.8177 | 1.9136 → 1.9057 |
| MPI-ESM1-2-LR | +0.0877 → +0.0876 | 0.7346 → 0.7347 | 0.7409 → 0.7409 | 1.7069 → 1.7065 |
| CanESM5 | +0.0820 → +0.0818 | 0.8989 → 0.8989 | 0.7041 → 0.7039 | 1.6848 → 1.6841 |

平均偏差和RMSE单位为mol C m⁻² yr⁻¹，积分单位为Pg C/yr。MPI和CanESM5几乎不变；GFDL变化
稍大，但仍不足以改变模式排序。GFDL订正后平均偏差略减，而RMSE略增，说明漂移订正并不保证与
观测更接近：它依据控制试验独立识别虚假趋势，而不是为了优化模式—观测拟合。

| CanESM5 | 印度洋 | +0.218 | 0.529 | 0.772 | +0.095 |

平均偏差和RMSE单位为mol C m⁻² yr⁻¹。

### 4.1 表现较好的海区

- 三个模式均再现了赤道太平洋放气、北大西洋和北太平洋吸收、南半球中纬度吸收带这些一级结构。
- GFDL的南大洋平均偏差只有+0.057，且赤道太平洋型相关达到0.862，是三模式中空间位置最可信的。
- MPI的北大西洋RMSE为0.720，在三模式中最低；其印度洋型相关也较高。
- CanESM5在印度洋和赤道太平洋仍能再现大尺度正负结构，但幅度存在系统偏差。

### 4.2 最大偏差及偏差类型

1. **南大洋吸收不足**：MPI偏差−0.332，CanESM5为−0.509 mol C m⁻² yr⁻¹。CanESM5的区域
   积分少吸收约0.335 Pg C/yr，是最明显的区域总量偏差。GFDL在该纬度带明显更接近观测。
2. **北大西洋吸收过强**：三个模式均为正偏差，其中GFDL和CanESM5分别为+0.589和+0.473。
3. **赤道太平洋放气幅度不同**：GFDL偏差为负，表示放气过强；MPI和CanESM5偏差为正，表示
   放气过弱。
4. **北太平洋位置与强度均有误差**：三模式在该区的RMSE都是各自五个区域中最大或接近最大。
   GFDL和MPI的区域平均偏差较小，但偏差图呈相邻正负偶极，说明问题主要是吸收带的位置或宽度，
   而不是区域总量；CanESM5还叠加了明显的吸收过强（+0.537）。
5. **印度洋普遍吸收过强**：Landschützer区域平均接近中性，三模式却均有约+0.22至+0.26的正偏差。

综合判断：GFDL-ESM4的空间型总体最可信；MPI-ESM1-2-LR居中，但南大洋和赤道太平洋幅度偏弱；
CanESM5在南大洋吸收不足、北太平洋吸收过强和北大西洋结构偏差方面最突出。

漂移订正没有改变以上区域结论。变化最大的是GFDL北太平洋：平均偏差由+0.096降到+0.077，但
RMSE由1.229升到1.280，仍然支持“区域平均量接近、局地位置偏差较大”的判断。

## 5. 图件和限制

- `figures/spatial_flux_climatology_drift_corrected.png`：按当前漂移判据局地订正后的观测—模式气候态
  对比，是正式气候态图。
- `figures/spatial_bias_maps_drift_corrected.png`：局地漂移订正后模式减Landschützer的正式空间偏差图；
  蓝色表示模式吸收过强，红色表示吸收过弱或放气过强。
- `figures/spatial_raw_p05_vs_fdr.png`：逐格原始\(p<0.05\)与FDR订正后保留区域的对比。
- `figures/spatial_drift_required_regions.png`：完整累计漂移场，以及同时满足FDR和实际幅度阈值的局地
  订正区域。
- `tables/global_spatial_metrics_drift_corrected.csv`和
  `tables/regional_spatial_metrics_drift_corrected.csv`：订正后的
  全球与分区指标。
- `tables/spatial_raw_p05_native_gridcells.csv`：所有原生网格\(p<0.05\)格点的经纬度、趋势、\(p\)值、
  FDR状态和是否需要订正。

主要限制：Landschützer v2016为未经GCB全局归一化的原始产品，其全球积分不能替代GCB年序列；
2°面积汇总不是严格多边形重叠重网格；沿岸和海冰边缘对掩膜选择较敏感；当前只比较一个集合成员和
一个多年平均，不能检验季节相位或年际变化。

## 6. 复现

在项目根目录运行：

```powershell
python scripts/02_spatial_distribution/01_prepare_fields.py
python scripts/02_spatial_distribution/02_drift_correction.py
python scripts/02_spatial_distribution/03_plot.py
```

依赖为NumPy、pandas、SciPy、xarray、cftime、netCDF4和Matplotlib。代码不依赖Cartopy、xESMF或外部地图
服务，海岸线直接读取项目中的GeoJSON文件。
